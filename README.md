## 🚀 Featured Project: Apex Credit Systems

[![Live Web Dashboard](https://img.shields.io/badge/Live_App-Render-4f46e5?style=for-the-badge&logo=render)](https://loan-approval-app-c7y0.onrender.com/)
[![GitHub Repo](https://img.shields.io/badge/GitHub-Repo-10b981?style=for-the-badge&logo=github)](https://github.com/YashkumarBhatt/Apex-Credit-Systems)

**Apex Credit Systems** is an end-to-end, enterprise-grade machine learning underwriting platform and cross-platform mobile suite. 

**Key Highlights:**
- **🧠 Dual-Track Machine Learning:** Solved credit-invisible bias by serving both established credit applicants (Random Forest ensemble) and thin-file borrowers (Capacity & DTI engine).
- **🌐 Full-Stack Architecture:** Built with a decoupled **FastAPI** backend and a custom glassmorphism vanilla **JavaScript/CSS3** frontend dashboard.
- **📱 Cross-Platform Mobile:** Shipped a lightweight Capacitor Web Wrapper (4 MB) and a standalone **React Native** application (75 MB) for field analysts.
- **☁️ Cloud Deployed:** Live on Render with encrypted environment variables, robust OAuth2/JWT security, and multi-factor Master Admin controls.
